# Shed — обновления

Официальный канал обновлений приложения расписания Shed для группы ПР126.

Здесь нет исходного кода приложения. Готовый APK публикуется в разделе
[Releases](../../releases/latest), а файл `update.json` используется встроенной
проверкой обновлений.

Приложение перед установкой проверяет SHA-256 загруженного APK.
